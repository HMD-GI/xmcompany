# XMCompany 公司管理系统前端（Vue3）

## 技术栈
- Vue3 + Vite
- Element Plus
- Pinia
- Vue Router
- Axios

## 目录结构
- `src/api/`：接口请求封装
- `src/pages/`：业务页面
- `src/components/`：通用组件
- `src/layouts/`：布局
- `src/router/`：路由
- `src/store/`：状态管理
- `src/utils/`：工具函数

## 启动方式
```bash
npm install
npm run dev
```

## 说明
- 默认后端接口地址为 `http://localhost:8080`，可在 `src/api/request.js` 中修改。
- 详细接口见 `XMCompany接口文档.md`。
